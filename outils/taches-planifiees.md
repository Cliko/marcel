Pour Ben (role admin), garde ses habitudes : poids du corps sans barre, sortie vélo de route, piscine, tests du dimanche (records push, pull = rowing table, plank) et ses paliers. ## Vendredi 7 h 13 : « Recettes de la semaine suivante »

1) Dépôt Cliko/marcel (add_repo en accès push s'il n'est pas attaché ; git pull sur main). Lis README.md et js/contenu.js (questions Q_NUTRI). `node outils/publier.js profils` ; ignore les profils sans questionnaire nutrition (nutrition_maj null).

2) Pour chaque profil, lis le suivi de la semaine en cours : `node outils/publier.js progression <email> sXX` (data.food : daily = où la personne a mangé à chaque repas (batch, maison, ext = extérieur…), water, batch = recettes faites, pick = recettes décochées (false)).

Respecte STRICTEMENT les allergies (allergies + allergies_autres : aucune recette qui en contient, même en trace évidente) et le régime ; exclus les aliments évités ; nombre de recettes = recettes, parts = parts, prix max par part = budget, temps de préparation ≤ temps ; collations ou desserts seulement si collations = oui. suivi_quotidien : un élément de type "repas" pour chaque repas prévu (options comme dans nutritionDemarrage de js/contenu.js), l'eau si suivi contient eau ; défis (quêtes) si suivi contient defis.
